# 极地航线决策台 · Polar Route Decision Console

零依赖单页交互应用：在浮冰海域海图上动态推演船体位置、浮冰漂移、风场、能见度、燃料与通信覆盖；
交互式调整航线、航速与等待窗口，实时重算 ETA、航段风险与连锁影响；支持暂停、从历史节点分叉重推，
以及通信中断期间的离线操作暂存与恢复后合并。

## 运行

无需构建，直接用浏览器打开即可：

```bash
open index.html
# 或：python3 -m http.server 8000 然后访问 http://localhost:8000/
```

## 功能清单

**动态海图**
- 三条随时间漂移的高风险冰带（密集度热图 + 边界椭圆）与 64 块独立浮冰（各自漂移/旋转）
- 风矢网格（风速、风向随时间演化，大风期约在 D1 傍晚 / D2 凌晨）
- 能见度雾区（半透明雾层，D1 夜间与 D3 凌晨两个低能见度窗口）
- 四个通信覆盖圈（长城岸站 + 三个中继浮标），船驶出覆盖即自动离线
- 船体实时位置/艏向/局地风险环、已航迹、冰阻后的实际航速

**航线决策**
- 拖动航路点改线；双击航段空白处插入航路点、双击可移除航路点删除（补给点 WP3 固定）
- 顶栏切换航速 6/8/10/12 kn；每个航路点可设置到点后的等待窗口（分钟）
- 点击任意航段查看：段长、预计进入时刻、冰密集度峰值、风险均值/峰值、段内无链路时长、逐小时风险柱
- 已驶过的航路点不可直接修改，需从历史节点分叉后调整

**预测与连锁影响（右侧面板，任何编辑后即时重算）**
- 72 小时全程方案预测（从起点重放，保证历史航段可查）+ 当前船位起的剩余航程 ETA/抵达燃料
- 风险 = 冰密集度 70% 权重 + 大风（>12 m/s）+ 低能见度（<3 km），分低/中/高/极高四级
- 连锁影响卡片明确给出传导链，例如：
  - 穿越高风险冰带 → 冰阻降速 → 油耗上升 → ETA 推迟、燃料缓冲收窄
  - 错过补给窗口（D2 02:00–16:00）→ 无法补油 → 后续航段燃料耗尽、漂航，且补给点以北为盲区无法呼叫
  - 早到补给 → 怠速等待开窗 → ETA 顺延
  - 通信盲区与高风险冰带重叠 → 岸基支持不可用、离线操作冲突处置延迟
  - 低能见度/大风 → 建议等待或降速，附保守延误估计

**时间控制与历史**
- 开始/暂停、+30 分单步、×1/×5/×15/×60 小时倍速
- 每 30 仿真分钟及每次编辑/关键事件（进冰带、补给、断油等）自动存档
- 底部时间轴标注：离线段（紫色）、补给窗口（橙色带）、自动节点（小圆点）、编辑节点（大圆点）、当前时刻
- 点击时间轴上的历史节点即**分叉**出新的推演分支，右侧"历史分支"可随时进入/删除，主线自动存盘

**离线操作与合并**
- 点击"模拟通信中断"或驶出覆盖区后进入离线态（船体变紫、航线叠紫色虚线）
- 离线期间的改航速/改等待/移动/增删航路点均以操作记录本地暂存（拖动合并为一条移动操作）
- 通信恢复后弹出同步面板：逐项标注操作是否仍可重放（目标航路点被删则标失效、不可勾选）
- 合并基于"岸上最后确认版本"重放勾选项，支持全部丢弃；合并后自动重算全部预测与连锁影响

## 想定参数（便于演示各风险链条）

- 海域 490 km × 315 km；默认航线 525 km，10 kn 约 35 h 抵达，途中在 D2 05:00 完成补给
- 6 kn 抗冰速 + WP2 等待 6 h：预计 D3 01:22 错过补给窗口 → D3 16:06 燃料耗尽（完整断油链）
- 12 kn 全速：约早到 40 分钟，怠速等开窗后补油
- 把 WP2 拖入第一条冰带中心：风险升至极高，ETA 与油耗连锁变化
